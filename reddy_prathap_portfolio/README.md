# Reddy Prathap Derangula — Portfolio

A responsive, animated personal portfolio built with HTML, CSS and vanilla JavaScript.

## Run locally
1. Extract this ZIP.
2. Open `index.html` in Chrome, Edge or Firefox.

For the best local preview, use the VS Code Live Server extension.

## Photo and resume
Your uploaded portrait is included as `assets/profile-photo.jpg` and is displayed in the hero section. Your uploaded resume is included as `assets/Reddy_Prathap_Resume.pdf` and linked from the Resume section.

## Publish free with GitHub Pages
1. Create a new public repository on GitHub, for example `prathap-portfolio`.
2. Upload all files and folders from this extracted project (keep `index.html` in the repository root).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then Save.
6. Wait for the Pages URL shown in that section.
